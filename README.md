# Funcode Code Analyzer

**Funcode Studio CB**

Analizador estático de proyectos de software completos. Recibe un único archivo `.zip` o `.rar`, lo descomprime
de forma segura (sin ejecutar nada) y genera un diagnóstico técnico: estructura, tecnologías, arquitectura,
relaciones entre archivos, dependencias y auditoría de seguridad, exportable en PDF, HTML y JSON.
